# Изменения для режима "Регионы" - Заполнение столбцов "Коммент." и "Место"

## Описание задачи
Обновлено заполнение столбцов "Коммент." и "Место" для режима "Регионы" в соответствии с новыми требованиями.

## Внесённые изменения

### 1. Функция `enrichWithSchedule` (строка 1020)
**Изменение:** Установлено значение `'Коммент.': 'Текстиль'` для всех обычных записей.

**Было:**
```javascript
'Коммент.': ''
```

**Стало:**
```javascript
'Коммент.': 'Текстиль'
```

**Результат:** Все записи из отчёта теперь имеют в столбце "Коммент." значение "Текстиль".

---

### 2. Функция `addPOSMRows` - Столбец "Коммент." (строки 1047-1064)
**Изменение:** Обновлена логика формирования комментариев для POSM-записей.

**Было:**
```javascript
const name = (getColumnValue(row, 'Наименование', 'наименование') || '').toString().toLowerCase();
let comment = 'Оборудование';
if (name.includes('трансфер')) {
    comment = 'трансфер';
} else if (name.includes('posm')) {
    comment = 'POSM';
}
```

**Стало:**
```javascript
const nameOriginal = (getColumnValue(row, 'Наименование', 'наименование') || '').toString().trim();
const nameLower = nameOriginal.toLowerCase();
let recordType = 'Оборудование';
if (nameLower.includes('трансфер')) {
    recordType = 'Трансфер';
} else if (nameLower.includes('posm')) {
    recordType = 'POSM';
}

const size = (getColumnValue(row, 'Размер', 'размер') || '').toString().trim();
const weight = (getColumnValue(row, 'Вес', 'вес') || '').toString().trim();

const commentParts = [recordType];
if (nameOriginal) commentParts.push(nameOriginal);
if (size) commentParts.push(size);
if (weight) commentParts.push(weight);
const comment = commentParts.join(' ');
```

**Результат:** 
- Комментарий формируется в формате: `[Тип] [Наименование] [Размер] [Вес]`
- Тип определяется по содержимому поля "Наименование":
  - Содержит "трансфер" → "Трансфер"
  - Содержит "posm" → "POSM"
  - Иначе → "Оборудование"
- Отсутствующие поля автоматически пропускаются

---

### 3. Функция `addPOSMRows` - Столбец "Место" (строки 1058, 1072)
**Изменение:** Изменён источник данных для столбца "Место" в POSM-записях.

**Было:**
```javascript
const mesto = size && weight ? `${size} ${weight}` : (size || weight || '');
// ...
'Место': mesto,
```

**Стало:**
```javascript
const osNumber = (getColumnValue(row, 'ОС', 'ос', 'Номер ОС', 'номер ос') || '').toString().trim();
// ...
'Место': osNumber,
```

**Результат:** 
- Для POSM-записей в столбец "Место" теперь берутся данные из столбца "ОС" файла POSM
- Размер и вес остались в столбце "Коммент."
